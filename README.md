# Birthday Surprise

A romantic static birthday website with a password gate, photo gallery, memories page, love letter, and final surprise.

## Files

- `index.html` — password gate
- `birthday.html` — main birthday landing page
- `memories.html` — favorite memories section
- `gallery.html` — gallery page for your photos
- `love-letter.html` — heartfelt love note
- `our-journey.html` — your shared journey
- `final-surprise.html` — final emotional message
- `css/style.css` — design and layout
- `js/script.js` — password gate and small animations
- `images/` — add your personal photos here
- `audio/` — optional romantic music can go here

## How to use it

1. Open `index.html` in a browser.
2. Enter the passcode: `love2026`
3. Explore the pages and replace the placeholder gallery images with your own.

## Customize it

- Change the passcode in `js/script.js`.
- Replace placeholder art in `images/` with your real photos.
- Add music by placing a `.mp3` file in `audio/` and linking it from one of the pages.

## Notes

This is a front-end website, so no server is required.
